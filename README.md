# 年金・収入・手取りシミュレーター

日本の年金、給与、副業・事業、家賃、投資などから税金・社会保険料・手取りを概算する静的Webアプリです。

公開ページ: https://rttrzdf.github.io/nenkin-simulator/

## ソースと公開
`index.html` が画面と計算ロジックを含む正本です。外部ライブラリ・サーバー・ビルド用パッケージは不要です。旧版の圧縮転送データは通常のHTMLに戻しました。

`bash build-site.sh ./_site` で公開用フォルダーへコピーし、コピーの完全一致を確認します。mainへのpushで既存のPagesワークフローが公開します。

## 追加検証
`tests/browser-audit.py` は公開ページとPR内の候補を区別し、Chromium・WebKit・Firefoxで実URL操作、実ストレージの保存・復元、プロセス再起動を検証します。GitHub Actionsの実行結果は各PRで確認してください。WebKitのモバイルエミュレーションはiPhone実機の代用ではありません。

## 計算の範囲
2026年の固定制度・東京/新宿区・単身モデルです。v2.0.1では介護保険の給与所得調整を修正しました。この2026年度特例も固定モデルの全期間へ適用し、将来制度を予測しません。

所得税等の計算額と最終納付額は異なります。年末調整・確定申告の納付時100円未満切捨て、源泉徴収済額との精算、各取引単位の端数は再現しません。全税目、全国の自治体、家族構成、不動産特例、損失繰越、退職金の複数受取等に完全対応するものではありません。画面末尾の前提と公式出典を確認してください。

税務申告・納付・年金請求の確定判断には公式資料や専門家による個別確認が必要です。
